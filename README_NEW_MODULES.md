# Новые модули для Помощника в общежитии

## Обзор

Добавлены три новых модуля для улучшения функционала приложения:

### 1. Заявки на ремонт
- Жильцы могут создавать заявки на ремонт с указанием места, категории проблемы и описания
- Статусы заявок: Ожидает, В работе, Выполнено, Отклонено
- Категории: Сантехника, Электрика, Мебель, Отопление, Окна/Двери, Другое
- Хранение данных на клиенте (localStorage)

### 2. Обмен вещами между жильцами
- Доска объявлений для обмена, дарения или продажи вещей
- Типы объявлений: Отдам даром, Обмен, Продам
- Категории: Электроника, Мебель, Книги, Одежда, Посуда, Спорт, Другое
- Указание контактной информации для связи
- Хранение данных на клиенте (localStorage)

### 3. Объявления от администрации
- Важные новости и объявления для всех жильцов
- Уровни приоритета: Важно, Средний, Информация
- Красивое визуальное оформление для важных объявлений
- Хранение данных на клиенте (localStorage)

## Особенности реализации

### Хранение данных
- Все данные хранятся в localStorage браузера
- Не требуется бэкенд для работы модулей
- Данные сохраняются между сессиями

### Дефолтные данные
Каждый модуль автоматически инициализируется с примерами данных для демонстрации:
- 3 заявки на ремонт с разными статусами
- 4 объявления об обмене разных типов
- 4 объявления от администрации разной важности

### Пользовательский интерфейс
- Современный дизайн с градиентами и анимациями
- Адаптивная верстка для мобильных устройств
- Визуальная индикация своих объявлений/заявок
- Цветовая кодировка по типам и статусам
- Toast-уведомления о действиях

## Использование

### Запуск приложения
1. Откройте `index.html` в браузере
2. Используйте навигационное меню слева для переключения между модулями

### Заявки на ремонт
1. Перейдите в раздел "Заявки на ремонт"
2. Нажмите "Создать заявку"
3. Заполните форму: место, категория, описание проблемы
4. Ваша заявка появится в разделе "Мои заявки"
5. Все заявки видны в разделе "Все заявки"

### Обмен вещами
1. Перейдите в раздел "Обмен вещами"
2. Нажмите "Добавить объявление"
3. Заполните форму: название, категория, тип, описание, контакт
4. Ваше объявление появится в общем списке с отметкой

### Объявления администрации
1. Перейдите в раздел "Объявления"
2. Просмотрите важные новости от администрации
3. Объявления отсортированы по дате (новые сверху)
4. Важные объявления выделены красным

## Технические детали

### Структура данных

**Заявка на ремонт:**
```javascript
{
    id: number,
    userId: number,
    location: string,
    category: string,
    description: string,
    status: 'pending' | 'in-progress' | 'completed' | 'rejected',
    createdAt: string (ISO date)
}
```

**Объявление об обмене:**
```javascript
{
    id: number,
    userId: number,
    title: string,
    category: string,
    type: 'give' | 'exchange' | 'sell',
    description: string,
    contact: string,
    createdAt: string (ISO date)
}
```

**Объявление администрации:**
```javascript
{
    id: number,
    title: string,
    content: string,
    priority: 'high' | 'medium' | 'low',
    createdAt: string (ISO date)
}
```

### LocalStorage ключи
- `repairs` - массив заявок на ремонт
- `repairsNextId` - следующий ID для заявки
- `exchange` - массив объявлений об обмене
- `exchangeNextId` - следующий ID для объявления
- `announcements` - массив объявлений администрации

## Стилизация

### Цветовая схема
- Заявки на ремонт: Фиолетовый градиент
- Обмен (Отдам даром): Зеленый градиент
- Обмен (Обмен): Синий градиент
- Обмен (Продам): Оранжевый градиент
- Объявления: Розово-красный градиент

### Адаптивность
- Мобильные устройства (< 768px): одна колонка
- Планшеты (768px - 1024px): адаптивная сетка
- Десктоп (> 1024px): полноценная сетка
